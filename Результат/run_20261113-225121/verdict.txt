ВЕРОЯТНЫЕ ПРИЧИНЫ И ПОРЯДОК ДЕЙСТВИЙ
====================================================================================================

1. Сломаны/не установлены DRS-профили драйвера → 'isEnableHook: 0' для всех приложений   [вес 95, доля 27%]   ← начинай отсюда
   улики: log.drs_broken, log.first_severe, log.hooks_disabled
   1) Закрой NVIDIA App и переименуй C:\ProgramData\NVIDIA Corporation\Drs (nvdrsdb0.bin, nvdrsdb1.bin, BaseProfileDB.xml …) — драйвер пересоздаст базу.
   2) Перезагрузись, затем NVIDIA App → Настройки → 'Восстановить значения по умолчанию' для 3D-настроек; после этого включи оверлей/запись заново.
   3) Проверь, что у твоей учётки есть доступ на запись к HKLM\SOFTWARE\NVIDIA Corporation и к папке Drs: без прав профили читаются как 'пусто' (m_uiIndex: -1).
   4) Не помогло — переустановка драйвера 'Чистая установка' (кривые/модифицированные пакеты регулярно ломают DRS).
   5) Закрой NVIDIA App → переименуй C:\ProgramData\NVIDIA Corporation\Drs → перезагрузка (создастся заново).
   6) NVIDIA App → Настройки → сброс 3D-параметров → включить оверлей и запись заново.
   7) Далее — чистая переустановка официального драйвера (полный пакет, без вырезаний).
   8) NVIDIA App → Настройки → 'Внутриигровой оверлей' → Вкл (и 'Запись'/'Instant Replay' → Вкл).
   9) Крупный план: 'восстановить значения по умолчанию' в 3D-настройках и снять 'Off' для 'Внутриигровой оверлей' в профиле игры.
   10) Если рядом есть 'm_uiIndex: -1' — настройка не читается, а не выключена: см. log.drs_broken (сброс папки Drs).

2. Причина не сводится к типовым — нужен разбор лога   [вес 40, доля 11%]
   улики: log.crash_generic, log.unknown_errors, log.net, svc.summary, log.file_summary, log.not_nvidia, ev.clean
   1) Пришли report.txt и папку логов (scan --bundle diag.zip) — разберём строки перед первым 'fail'.
   2) Посмотри 'Имена сбойных пакетов' в Журнале Windows → Приложение (Application Error) — там Faulting module.
   3) Если модуль не nvidia*.dll — это конфликт стороннего софта, удаляй/отключай его.
   4) Ищи ПЕРВОЕ вхождение 'fail'/'error' сверху лога — обычно корень там, а всё после — каскад.
   5) Проверь время/дат (ошибки TLS), DNS, отсутствие MITM-прокси (Kaspersky Web Traffic, Palo Alto, Zscaler).
   6) Попробуй 'Не входить'/'локальный режим', если доступен.

3. Не с чем захватывать: Desktop Duplication / RDP / HDR / мультимонитор-гибрид (Optimus)   [вес 39, доля 11%]
   улики: log.record_fail, driver.hybrid, log.power_graphic, log.hdr, log.optimus_icon_noise
   1) Запись через RDP, быстрый запуск/выход из учётки, сессия 'Другой пользователь', виртуалка без GPU — оверлей не работает по дизайну.
   2) Ноутбук с Optimus/гибридной графикой: переключи вывод экрана на дискретную nVidia (MUX/dGPU-only), либо запиши через 'Захват рабочего стола' вместо 'Захват игры'.
   3) Выключи HDR (Параметры → Дисплей → HDR) и 'Аппаратное ускоречение планирования графического процесса' (HAGS) на тест, затем верни по одному.
   4) Закрой всё, что тоже делает DXGI duplication: OBS (проектор/витрина), Discord стрим, Xbox Game Bar запись, Miracast, удалённый доступ (Parsec/Sunshine/Moonlight).
   5) В мультимониторных схемах 'только второй экран' оверлей иногда цепляется не за тот вывод — попробуй 'Расширить эти экраны'.
   6) Сравни: 'Захват игры' vs 'Захват рабочего стола' — если рабочий стол пишется, а игра нет, дело в инъекции (см. конфликт/привилегии).
   7) Снизь качество до 1080p30/H.264/50 Мбит — проверь, не упирается ли в лимит.
   8) Отключи 'Автовыключение записи при потере фокуса' и 'Запись только в полноэкранном режиме'.
   9) Параметры → Система → Дисплей → Графика → для нужной игры 'Высокая производительность' (NVIDIA).
   10) Переключи ноутбук в dGPU-only/MUX и перезагрузись.
   11) Вместо 'Захват игры' попробуй 'Захват рабочего стола' — если работает, это точно гибрид.
   12) Параметры → Дисплей → Графика → выставь для игры 'Высокая производительность (NVIDIA)'.
   13) В BIOS/фирменной утилите (Legion Toolkit, MyASUS, Alienware Command) переключи 'dGPU only'/MUX.
   14) Питание → 'Максимальная производительность', не 'Экономия' на тест.
   15) Параметры → Дисплей → HDR → выкл на тест; в NVIDIA App отключи 'HDR' в настройках записи.
   16) Игнорируй. Но на гибридном ноутбуке проверь, что игра рендерится на NVIDIA: Параметры -> Дисплей -> Графика -> 'Высокая производительность'.

4. Не запускается сам процесс оверлея (NVIDIA Overlay.exe / CEF)   [вес 37, доля 11%]
   улики: log.igo_open_failed, log.overlay_not_ready, log.mmf_race, log.overlay_activity
   1) Проверь, что файл существует: C:\Program Files\NVIDIA Corporation\NVIDIA App\CEF\NVIDIA Overlay.exe
   2) Запусти NVIDIA App и нажми Alt+Z; подожди 10-20 с, затем Task Manager → детали → NVIDIA Overlay.exe.
   3) Добавь папку C:\Program Files\NVIDIA Corporation\NVIDIA App в исключения антивируса/Defender (папку целиком, не один exe).
   4) Отключи режим 'Экономия памяти'/совместимости, удали переменные окружения CEF_* и --disable-gpu-аккуратно: NVIDIA Overlay падает без аппаратного ускорения.
   5) Если в логах виден 'GPU process crash'/CEF assert → полный цикл: DDU (безопасный режим) → свежий драйвер с сайта NVIDIA App.
   6) Выгрузи стек начисто: выйди из App → taskkill /f /im "NVIDIA Overlay.exe" /t → перезапусти сервисы NVDisplay.ContainerLocalSystem, NvContainerLocalSystem → стартни App ОДИН раз.
   7) Проверь целостность установки: HKLM\SOFTWARE\NVIDIA Corporation\Installer2\Stripped не должен содержать ShadowPlay/NvStream (иначе — переустановка полного пакета).
   8) Переименуй кэш UI: %LOCALAPPDATA%\NVIDIA Corporation\NVIDIA App (CEF-кэш) — окно может не рисоваться из-за него.
   9) Выгрузи стек начисто: выйди из NVIDIA App (трей → Выход), затем taskkill /f /im "NVIDIA Overlay.exe" /t, PowerShell (админ): Restart-Service NVDisplay.ContainerLocalSystem,NvContainerLocalSystem -Force, и запусти App ОДИН раз (лишние экземпляры — типичный корень).
   10) Далее удали кэш CEF: переименуй %LOCALAPPDATA%\NVIDIA Corporation\NVIDIA App и %LOCALAPPDATA%\NVIDIA Corporation\NVIDIA Overlay (если есть), стартни App снова.
   11) Не помогло — смотри log.component_stripped и log.drs_broken: без компонента/профилей оверлей не поднимается независимо от перезапусков.
   12) Полная перезагрузка (не 'Завершение работы' с Fast Startup), затем один запуск NVIDIA App.
   13) Если сохраняется — убей все 'NVIDIA Overlay.exe' и стартни App один раз; смотри log.overlay_not_ready.
   14) taskkill /f /im "NVIDIA Overlay.exe"; убедиться, что App запускается ровно одним экземпляром (автозапуск + ручной запуск = два).

5. Оверлей вообще не пытается стартовать: в логах нет ни одной строки Overlay/Capture   [вес 28, доля 8%]
   улики: log.quiet, log.file_summary
   1) Значит проблема до оверлея: не поднят NVIDIA App (автозагрузка выключена) или убит его контейнер — см. Task Manager → Startup.
   2) Включи подробное логирование и повтори запуск: NVIDIA App → Помощь → 'Собрать отчёт' (или запусти NVIDIA App.exe с --debug).
   3) Проверь, что служба автозапуска не отключена оптимизаторами (Watcher/Predator/'ускорители Windows').
   4) Нажми Alt+Z, подожди 20 с, затем сразу снова запусти `scan` — свежие строки появятся.
   5) Включи расширенное логирование: NVIDIA App → Помощь → 'Собрать файлы отладки'.

6. Кривая/остаточная установка драйвера или версия ниже требуемой   [вес 25, доля 7%]
   улики: log.driver, log.first_severe, driver.old
   1) Свежий драйвер (не Windows Update), установка 'Выборочная' → 'Чистая установка'.
   2) После 'Чистой установки' перезагрузись и включи оверлей заново в NVIDIA App.
   3) Видишь в System Event Log 'nvlddmkm ... stopped responding' (TDR, ID 4101) — снизь разгон/UNDERT, отключи 'PowerMizer' тюнинг, MSI-Afterburner кривые.
   4) Если ставил модифицированные драйверы/NVCleanstInstall/NoDVA — верни официальные для теста.
   5) nvidia-smi в админ-консоли; 'no devices found' → Device Manager → Код 43 / не тот драйвер.
   6) Установи свежий драйвер с 'Чистой установкой', затем перезагрузись (не 'Завершение работы' с Fast Startup).
   7) Обнови драйвер до актуальной ветки (Studio или Game Ready), 'Чистая установка'.

7. Куда писать: папка записи недоступна/нет места/сеть-диск/OneDrive   [вес 21, доля 6%]
   улики: log.first_severe, log.storage
   1) Оставь минимум 20-30 ГБ свободных на диске записи; 'Capture folder' не должна быть на сетевом, съемном или зашифрованном (BitLocker-removable) диске.
   2) Убери папку записи из OneDrive/виртуальных папок 'Файлы по требованию' — иначе запись падает на середине.
   3) Путь без юникода/пробелов/символов # и & на время теста: D:\NVCapture.
   4) Проверь, что на папке есть Full Control для твоего пользователя (свойства → Безопасность).
   5) Освободи 20-30 ГБ и/или переназначь папку записи на локальный NTFS-диск.
   6) Убери из OneDrive/сети; добавь исключения для *.mp4 в AV.
   7) Проверь, что путь не длиннее 240 символов и не содержит запрещённых символов.

8. Не работает сервис/контейнер NVIDIA (nvcontainer / Display Container)   [вес 20, доля 6%]
   улики: log.container, log.first_severe
   1) PowerShell (админ): Get-Service *NVIDIA*,*Nv* | Select Name,Status,StartType — все NVIDIA-сервисы должны быть Running/Automatic.
   2) Перезапусти: Restart-Service NVDisplay.ContainerLocalSystem -Force; если есть NVIDIA App Container / NvidiaAppContainer — его тоже.
   3) Если сервис остановлен/отключён (StartType=Disabled): Set-Service <Имя> -StartupType Automatic; Start-Service <Имя>.
   4) Если не стартует — переустанови драйвер с галкой 'Чистая установка' (NVIDIA App → Драйверы), либо 'Изменить установки' → восстановить Component.
   5) Start-Service NVDisplay.ContainerLocalSystem (от админа) и проверь, что он не падает через 5 сек.
   6) Помогает переустановка 'только' компонентов: установщик драйвера → Выборочно → Graphics Driver + NVIDIA App.

9. Привилегии: игра/приложение запущены с повышенными правами, а оверлей — нет   [вес 13, доля 4%]
   улики: log.access_denied, priv.not_admin
   1) Оверлей не может показаться и перехватывать клавиши в окне, запущенном 'От имени администратора', если сам он обычный.
   2) Запусти NVIDIA App от имени администратора (или убери 'От имени администратора' с ярлыка игры).
   3) Отключи UAC-обход только для игры; не держи весь Windows под админом.
   4) Игры из Microsoft Store/UWP и античит-защищённые (EAC/Vanguard) часто режут оверлеи — там нужен режим совместимости игры в окне.
   5) Запусти NVIDIA App от администратора на время теста; убери 'Запуск от имени администратора' с ярлыка игры.
   6) Проверь права на папку записи и на C:\Program Files\NVIDIA Corporation\NVIDIA App.
   7) Запусти PowerShell от администратора и повтори: python nvidia_overlay_diag.py scan

10. Горячая клавиша не регистрируется / не тот ввод (Alt+Z перехвачен)   [вес 11, доля 3%]
   улики: log.hotkey, log.hotkey_reg_failed, log.hotkey_unbound
   1) Смени клавишу в NVIDIA App → Настройки → Горячие клавиши (например на F9), затем проверь в игре и на рабочем столе.
   2) Перехватчики: iCUE/Razer Synapse/Logitech G Hub/AutoHotkey/PowerToys FancyZones+Keyboard Manager, 'Win+G' назначенный другому.
   3) Раскладка: Alt+Z может 'теряться' при русской раскладке — переключись на EN и проверь.
   4) Если оверлей открывается, а клавиша нет — это не 'не запускается', а именно конфликт клавиш.
   5) Смени клавишу в настройках NVIDIA App; освободи её от iCUE/Synapse/G Hub/PowerToys/AutoHotkey.
   6) NVIDIA App → Настройки → Горячие клавиши → назначить заново Alt+Z и Alt+\, затем перезапустить App.
   7) Проверь, что HKCU не перенесён/не заблокирован (политики, Roaming-профиль, антивирус-защита реестра).
   8) NVIDIA App → Настройки → 'Горячие клавиши' → назначить заново Alt+Z (оверлей) и Alt+\ (реплей); после смены — перезапустить App.
   9) Если поле не сохраняется (слетает после перезапуска) — это конфиг/кэш: переименуй %LOCALAPPDATA%\NVIDIA Corporation\NVIDIA App и переустанови пакет.

11. Оверлей/запись выключены в настройках NVIDIA App (или политиками/реестром)   [вес 9, доля 3%]
   улики: reg.switch_off, log.overlay_disabled
   1) NVIDIA App → Настройки → 'Внутриигровой оверлей' → включить; 'Запись' / Instant Replay → включить и выбрать горячую клавишу.
   2) Проверь, что не стоит 'Только Studio Mode'/'Только скриншоты' и что выбран профиль записи.
   3) GPO: HKLM\SOFTWARE\Policies\NVIDIA Corporation — если там есть значения Overlay/Capture/Privacy=0, это политика ИТ-отдела, снимай через gpedit.
   4) После изменений выйди из NVIDIA App полностью (трей → Выход) и запусти заново, а не только закрой окно.
   5) Экспортируй ключ (.reg), потом ставь 1/0 по одному и проверяй Alt+Z.
   6) NVIDIA App → Настройки → внутриигровой оверлей → Вкл; затем полный выход из приложения и запуск.

12. NVIDIA App / GeForce Experience не установлен полностью или версии рассинхронизированы   [вес 7, доля 2%]
   улики: log.plugin_missing
   1) NVIDIA App и GFE одновременно ставить нельзя — останется 'висящая' установка, у которой оверлей не поднимается. Удали одно из двух (Параметры → Приложения).
   2) Помогает: удалить NVIDIA App, перегрузиться, поставить свежий установщик с nvidia.ru, выбрать 'Драйвер + NVIDIA App'.
   3) Если установка падает (Error 1606 / 'older version installed') — см. C:\Program Files\NVIDIA Corporation\Installer2\*.log
   4) Запусти установщик драйвера → 'Выборочная' → включи NVIDIA App (и 'Optimize...'/Video, если есть) → восстановление.
   5) Или просто: NVIDIA App → Помощь → 'Переустановить приложение'.

13. Повреждены настройки/кэш NVIDIA App (Settings.json, кэш CEF, конфиг профиля записи)   [вес 3, доля 1%]
   улики: cfg.no_settings
   1) Закрой NVIDIA App (трей → Выход), переименуй C:\ProgramData\NVIDIA Corporation\NVIDIA App\ (или GeForce Experience\) в *.bak и запусти приложение заново — настройки пересоздадутся.
   2) Локальный кэш: удали %LOCALAPPDATA%\NVIDIA Corporation\NVIDIA App\ (или 'NVIDIA GeForce Experience') — слетают настройки интерфейса, но часто чинит CEF-краш.
   3) Проверь, что папки ProgramData не 'Read-only' и пользователь имеет право записи.
   4) Запусти NVIDIA App хотя бы раз; затем повтори сканирование.

14. Блокировка запуска/инъекции защитником Windows (Controlled Folder Access, SmartScreen, Code Integrity/WDAC) или антивирусом   [вес 2, доля 1%]
   улики: sec.av
   1) Безопасность Windows → Защита вируса и угрозы → Управление приложениями и файлами (Controlled Folder Access) → 'Разрешить взаимодействие с приложением' → добавь NVIDIA App.exe и NVIDIA Overlay.exe.
   2) Просмотрите 'Журнал защиты' на предмет 'Заблокировано' для путей C:\Program Files\NVIDIA Corporation.
   3) Если стоит LRWDAC/WDAC/Policy Rule из корпоративной сборки — нужен исключительный policy для C:\Program Files\NVIDIA Corporation.
   4) Проверь, не в карантине ли NVIDIA Overlay.exe / nvcontainer.exe.
   5) Добавь ИСКЛЮЧЕНИЕ на папку C:\Program Files\NVIDIA Corporation (целиком) и на папку записи.
   6) На 5 минут отключи защиту и проверь Alt+Z: если заработало — точно блокировка, оформляй исключение постоянно.
   7) UAC/защита памяти в ESET/Kaspersky/Avast/Dr.Web: 'Мониторинг прямого доступа', 'Anti-STEALTH', 'Блокировка скриншотов' — выключить.

ПЛАН ДЕЙСТВИЙ (уникальные шаги, по приоритету)
========================================================================

— Сломаны/не установлены DRS-профили драйвера → 'isEnableHook: 0' для всех приложений
  1. Закрой NVIDIA App и переименуй C:\ProgramData\NVIDIA Corporation\Drs (nvdrsdb0.bin, nvdrsdb1.bin, BaseProfileDB.xml …) — драйвер пересоздаст базу.
  2. Перезагрузись, затем NVIDIA App → Настройки → 'Восстановить значения по умолчанию' для 3D-настроек; после этого включи оверлей/запись заново.
  3. Проверь, что у твоей учётки есть доступ на запись к HKLM\SOFTWARE\NVIDIA Corporation и к папке Drs: без прав профили читаются как 'пусто' (m_uiIndex: -1).
  4. Не помогло — переустановка драйвера 'Чистая установка' (кривые/модифицированные пакеты регулярно ломают DRS).
  5. Закрой NVIDIA App → переименуй C:\ProgramData\NVIDIA Corporation\Drs → перезагрузка (создастся заново).
  6. NVIDIA App → Настройки → сброс 3D-параметров → включить оверлей и запись заново.
  7. Далее — чистая переустановка официального драйвера (полный пакет, без вырезаний).
  8. NVIDIA App → Настройки → 'Внутриигровой оверлей' → Вкл (и 'Запись'/'Instant Replay' → Вкл).
  9. Крупный план: 'восстановить значения по умолчанию' в 3D-настройках и снять 'Off' для 'Внутриигровой оверлей' в профиле игры.
  10. Если рядом есть 'm_uiIndex: -1' — настройка не читается, а не выключена: см. log.drs_broken (сброс папки Drs).

— Причина не сводится к типовым — нужен разбор лога
  11. Пришли report.txt и папку логов (scan --bundle diag.zip) — разберём строки перед первым 'fail'.
  12. Посмотри 'Имена сбойных пакетов' в Журнале Windows → Приложение (Application Error) — там Faulting module.
  13. Если модуль не nvidia*.dll — это конфликт стороннего софта, удаляй/отключай его.
  14. Ищи ПЕРВОЕ вхождение 'fail'/'error' сверху лога — обычно корень там, а всё после — каскад.
  15. Проверь время/дат (ошибки TLS), DNS, отсутствие MITM-прокси (Kaspersky Web Traffic, Palo Alto, Zscaler).
  16. Попробуй 'Не входить'/'локальный режим', если доступен.

— Не с чем захватывать: Desktop Duplication / RDP / HDR / мультимонитор-гибрид (Optimus)
  17. Запись через RDP, быстрый запуск/выход из учётки, сессия 'Другой пользователь', виртуалка без GPU — оверлей не работает по дизайну.
  18. Ноутбук с Optimus/гибридной графикой: переключи вывод экрана на дискретную nVidia (MUX/dGPU-only), либо запиши через 'Захват рабочего стола' вместо 'Захват игры'.
  19. Выключи HDR (Параметры → Дисплей → HDR) и 'Аппаратное ускоречение планирования графического процесса' (HAGS) на тест, затем верни по одному.
  20. Закрой всё, что тоже делает DXGI duplication: OBS (проектор/витрина), Discord стрим, Xbox Game Bar запись, Miracast, удалённый доступ (Parsec/Sunshine/Moonlight).
  21. В мультимониторных схемах 'только второй экран' оверлей иногда цепляется не за тот вывод — попробуй 'Расширить эти экраны'.
  22. Сравни: 'Захват игры' vs 'Захват рабочего стола' — если рабочий стол пишется, а игра нет, дело в инъекции (см. конфликт/привилегии).
  23. Снизь качество до 1080p30/H.264/50 Мбит — проверь, не упирается ли в лимит.
  24. Отключи 'Автовыключение записи при потере фокуса' и 'Запись только в полноэкранном режиме'.
  25. Параметры → Система → Дисплей → Графика → для нужной игры 'Высокая производительность' (NVIDIA).
  26. Переключи ноутбук в dGPU-only/MUX и перезагрузись.
  27. Вместо 'Захват игры' попробуй 'Захват рабочего стола' — если работает, это точно гибрид.
  28. Параметры → Дисплей → Графика → выставь для игры 'Высокая производительность (NVIDIA)'.
  29. В BIOS/фирменной утилите (Legion Toolkit, MyASUS, Alienware Command) переключи 'dGPU only'/MUX.
  30. Питание → 'Максимальная производительность', не 'Экономия' на тест.
  31. Параметры → Дисплей → HDR → выкл на тест; в NVIDIA App отключи 'HDR' в настройках записи.
  32. Игнорируй. Но на гибридном ноутбуке проверь, что игра рендерится на NVIDIA: Параметры -> Дисплей -> Графика -> 'Высокая производительность'.

— Не запускается сам процесс оверлея (NVIDIA Overlay.exe / CEF)
  33. Проверь, что файл существует: C:\Program Files\NVIDIA Corporation\NVIDIA App\CEF\NVIDIA Overlay.exe
  34. Запусти NVIDIA App и нажми Alt+Z; подожди 10-20 с, затем Task Manager → детали → NVIDIA Overlay.exe.
  35. Добавь папку C:\Program Files\NVIDIA Corporation\NVIDIA App в исключения антивируса/Defender (папку целиком, не один exe).
  36. Отключи режим 'Экономия памяти'/совместимости, удали переменные окружения CEF_* и --disable-gpu-аккуратно: NVIDIA Overlay падает без аппаратного ускорения.
  37. Если в логах виден 'GPU process crash'/CEF assert → полный цикл: DDU (безопасный режим) → свежий драйвер с сайта NVIDIA App.
  38. Выгрузи стек начисто: выйди из App → taskkill /f /im "NVIDIA Overlay.exe" /t → перезапусти сервисы NVDisplay.ContainerLocalSystem, NvContainerLocalSystem → стартни App ОДИН раз.
  39. Проверь целостность установки: HKLM\SOFTWARE\NVIDIA Corporation\Installer2\Stripped не должен содержать ShadowPlay/NvStream (иначе — переустановка полного пакета).
  40. Переименуй кэш UI: %LOCALAPPDATA%\NVIDIA Corporation\NVIDIA App (CEF-кэш) — окно может не рисоваться из-за него.
  41. Выгрузи стек начисто: выйди из NVIDIA App (трей → Выход), затем taskkill /f /im "NVIDIA Overlay.exe" /t, PowerShell (админ): Restart-Service NVDisplay.ContainerLocalSystem,NvContainerLocalSystem -Force, и запусти App ОДИН раз (лишние экземпляры — типичный корень).
  42. Далее удали кэш CEF: переименуй %LOCALAPPDATA%\NVIDIA Corporation\NVIDIA App и %LOCALAPPDATA%\NVIDIA Corporation\NVIDIA Overlay (если есть), стартни App снова.
  43. Не помогло — смотри log.component_stripped и log.drs_broken: без компонента/профилей оверлей не поднимается независимо от перезапусков.
  44. Полная перезагрузка (не 'Завершение работы' с Fast Startup), затем один запуск NVIDIA App.
  45. Если сохраняется — убей все 'NVIDIA Overlay.exe' и стартни App один раз; смотри log.overlay_not_ready.
  46. taskkill /f /im "NVIDIA Overlay.exe"; убедиться, что App запускается ровно одним экземпляром (автозапуск + ручной запуск = два).

— Оверлей вообще не пытается стартовать: в логах нет ни одной строки Overlay/Capture
  47. Значит проблема до оверлея: не поднят NVIDIA App (автозагрузка выключена) или убит его контейнер — см. Task Manager → Startup.
  48. Включи подробное логирование и повтори запуск: NVIDIA App → Помощь → 'Собрать отчёт' (или запусти NVIDIA App.exe с --debug).
  49. Проверь, что служба автозапуска не отключена оптимизаторами (Watcher/Predator/'ускорители Windows').
  50. Нажми Alt+Z, подожди 20 с, затем сразу снова запусти `scan` — свежие строки появятся.
  51. Включи расширенное логирование: NVIDIA App → Помощь → 'Собрать файлы отладки'.

— Кривая/остаточная установка драйвера или версия ниже требуемой
  52. Свежий драйвер (не Windows Update), установка 'Выборочная' → 'Чистая установка'.
  53. После 'Чистой установки' перезагрузись и включи оверлей заново в NVIDIA App.
  54. Видишь в System Event Log 'nvlddmkm ... stopped responding' (TDR, ID 4101) — снизь разгон/UNDERT, отключи 'PowerMizer' тюнинг, MSI-Afterburner кривые.
  55. Если ставил модифицированные драйверы/NVCleanstInstall/NoDVA — верни официальные для теста.
  56. nvidia-smi в админ-консоли; 'no devices found' → Device Manager → Код 43 / не тот драйвер.
  57. Установи свежий драйвер с 'Чистой установкой', затем перезагрузись (не 'Завершение работы' с Fast Startup).
  58. Обнови драйвер до актуальной ветки (Studio или Game Ready), 'Чистая установка'.

— Куда писать: папка записи недоступна/нет места/сеть-диск/OneDrive
  59. Оставь минимум 20-30 ГБ свободных на диске записи; 'Capture folder' не должна быть на сетевом, съемном или зашифрованном (BitLocker-removable) диске.
  60. Убери папку записи из OneDrive/виртуальных папок 'Файлы по требованию' — иначе запись падает на середине.
  61. Путь без юникода/пробелов/символов # и & на время теста: D:\NVCapture.
  62. Проверь, что на папке есть Full Control для твоего пользователя (свойства → Безопасность).
  63. Освободи 20-30 ГБ и/или переназначь папку записи на локальный NTFS-диск.
  64. Убери из OneDrive/сети; добавь исключения для *.mp4 в AV.
  65. Проверь, что путь не длиннее 240 символов и не содержит запрещённых символов.

— Не работает сервис/контейнер NVIDIA (nvcontainer / Display Container)
  66. PowerShell (админ): Get-Service *NVIDIA*,*Nv* | Select Name,Status,StartType — все NVIDIA-сервисы должны быть Running/Automatic.
  67. Перезапусти: Restart-Service NVDisplay.ContainerLocalSystem -Force; если есть NVIDIA App Container / NvidiaAppContainer — его тоже.
  68. Если сервис остановлен/отключён (StartType=Disabled): Set-Service <Имя> -StartupType Automatic; Start-Service <Имя>.
  69. Если не стартует — переустанови драйвер с галкой 'Чистая установка' (NVIDIA App → Драйверы), либо 'Изменить установки' → восстановить Component.
  70. Start-Service NVDisplay.ContainerLocalSystem (от админа) и проверь, что он не падает через 5 сек.
  71. Помогает переустановка 'только' компонентов: установщик драйвера → Выборочно → Graphics Driver + NVIDIA App.

— Привилегии: игра/приложение запущены с повышенными правами, а оверлей — нет
  72. Оверлей не может показаться и перехватывать клавиши в окне, запущенном 'От имени администратора', если сам он обычный.
  73. Запусти NVIDIA App от имени администратора (или убери 'От имени администратора' с ярлыка игры).
  74. Отключи UAC-обход только для игры; не держи весь Windows под админом.
  75. Игры из Microsoft Store/UWP и античит-защищённые (EAC/Vanguard) часто режут оверлеи — там нужен режим совместимости игры в окне.
  76. Запусти NVIDIA App от администратора на время теста; убери 'Запуск от имени администратора' с ярлыка игры.
  77. Проверь права на папку записи и на C:\Program Files\NVIDIA Corporation\NVIDIA App.
  78. Запусти PowerShell от администратора и повтори: python nvidia_overlay_diag.py scan

— Горячая клавиша не регистрируется / не тот ввод (Alt+Z перехвачен)
  79. Смени клавишу в NVIDIA App → Настройки → Горячие клавиши (например на F9), затем проверь в игре и на рабочем столе.
  80. Перехватчики: iCUE/Razer Synapse/Logitech G Hub/AutoHotkey/PowerToys FancyZones+Keyboard Manager, 'Win+G' назначенный другому.
  81. Раскладка: Alt+Z может 'теряться' при русской раскладке — переключись на EN и проверь.
  82. Если оверлей открывается, а клавиша нет — это не 'не запускается', а именно конфликт клавиш.
  83. Смени клавишу в настройках NVIDIA App; освободи её от iCUE/Synapse/G Hub/PowerToys/AutoHotkey.
  84. NVIDIA App → Настройки → Горячие клавиши → назначить заново Alt+Z и Alt+\, затем перезапустить App.
  85. Проверь, что HKCU не перенесён/не заблокирован (политики, Roaming-профиль, антивирус-защита реестра).
  86. NVIDIA App → Настройки → 'Горячие клавиши' → назначить заново Alt+Z (оверлей) и Alt+\ (реплей); после смены — перезапустить App.
  87. Если поле не сохраняется (слетает после перезапуска) — это конфиг/кэш: переименуй %LOCALAPPDATA%\NVIDIA Corporation\NVIDIA App и переустанови пакет.

— Оверлей/запись выключены в настройках NVIDIA App (или политиками/реестром)
  88. NVIDIA App → Настройки → 'Внутриигровой оверлей' → включить; 'Запись' / Instant Replay → включить и выбрать горячую клавишу.
  89. Проверь, что не стоит 'Только Studio Mode'/'Только скриншоты' и что выбран профиль записи.
  90. GPO: HKLM\SOFTWARE\Policies\NVIDIA Corporation — если там есть значения Overlay/Capture/Privacy=0, это политика ИТ-отдела, снимай через gpedit.
  91. После изменений выйди из NVIDIA App полностью (трей → Выход) и запусти заново, а не только закрой окно.
  92. Экспортируй ключ (.reg), потом ставь 1/0 по одному и проверяй Alt+Z.
  93. NVIDIA App → Настройки → внутриигровой оверлей → Вкл; затем полный выход из приложения и запуск.

— NVIDIA App / GeForce Experience не установлен полностью или версии рассинхронизированы
  94. NVIDIA App и GFE одновременно ставить нельзя — останется 'висящая' установка, у которой оверлей не поднимается. Удали одно из двух (Параметры → Приложения).
  95. Помогает: удалить NVIDIA App, перегрузиться, поставить свежий установщик с nvidia.ru, выбрать 'Драйвер + NVIDIA App'.
  96. Если установка падает (Error 1606 / 'older version installed') — см. C:\Program Files\NVIDIA Corporation\Installer2\*.log
  97. Запусти установщик драйвера → 'Выборочная' → включи NVIDIA App (и 'Optimize...'/Video, если есть) → восстановление.
  98. Или просто: NVIDIA App → Помощь → 'Переустановить приложение'.

— Повреждены настройки/кэш NVIDIA App (Settings.json, кэш CEF, конфиг профиля записи)
  99. Закрой NVIDIA App (трей → Выход), переименуй C:\ProgramData\NVIDIA Corporation\NVIDIA App\ (или GeForce Experience\) в *.bak и запусти приложение заново — настройки пересоздадутся.
  100. Локальный кэш: удали %LOCALAPPDATA%\NVIDIA Corporation\NVIDIA App\ (или 'NVIDIA GeForce Experience') — слетают настройки интерфейса, но часто чинит CEF-краш.
  101. Проверь, что папки ProgramData не 'Read-only' и пользователь имеет право записи.
  102. Запусти NVIDIA App хотя бы раз; затем повтори сканирование.

— Блокировка запуска/инъекции защитником Windows (Controlled Folder Access, SmartScreen, Code Integrity/WDAC) или антивирусом
  103. Безопасность Windows → Защита вируса и угрозы → Управление приложениями и файлами (Controlled Folder Access) → 'Разрешить взаимодействие с приложением' → добавь NVIDIA App.exe и NVIDIA Overlay.exe.
  104. Просмотрите 'Журнал защиты' на предмет 'Заблокировано' для путей C:\Program Files\NVIDIA Corporation.
  105. Если стоит LRWDAC/WDAC/Policy Rule из корпоративной сборки — нужен исключительный policy для C:\Program Files\NVIDIA Corporation.
  106. Проверь, не в карантине ли NVIDIA Overlay.exe / nvcontainer.exe.
  107. Добавь ИСКЛЮЧЕНИЕ на папку C:\Program Files\NVIDIA Corporation (целиком) и на папку записи.
  108. На 5 минут отключи защиту и проверь Alt+Z: если заработало — точно блокировка, оформляй исключение постоянно.
  109. UAC/защита памяти в ESET/Kaspersky/Avast/Dr.Web: 'Мониторинг прямого доступа', 'Anti-STEALTH', 'Блокировка скриншотов' — выключить.

Команды-подсказки (ВЫПОЛНЯЙ САМ — скрипт ничего в системе не меняет):
  sc query type= all | findstr /i "nvidia"
  powershell -c "Get-Service *NVIDIA*,*Nv* | Select Name,Status,StartType"
  powershell -c "Restart-Service NVDisplay.ContainerLocalSystem -Force"
  powershell -c "Get-Process | Where-Object { $_.Path -like '*NVIDIA*' } | Select Name,Id,Path"
  nvidia-smi --query-gpu=name,driver_version,memory.total --format=csv
  powershell -c "Get-MpThreatDetection | Select-Object -First 10 InitialDetectionTime,Resources"
  powershell -c "Get-AppxPackage *NVIDIA* | Select Name,Version"
  powershell -c "Get-Process RTSS,MSIAfterburner -ErrorAction SilentlyContinue | Select Name,Id"
